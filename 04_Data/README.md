# Data

This directory contains the spatial, remote sensing, soil,
productivity, grid, and processed datasets used for district-level
carbon stock estimation in Ludhiana district.

## Large Files

Due to GitHub file-size limitations, the following large files are
stored externally on Google Drive:

- `lulc.tif`
- `02_Above_Ground_Predictions.zip`
- `03_Below_Ground_Predictions.zip`

### Google Drive

[Download Large Spatial Datasets](https://drive.google.com/drive/folders/1MH88jdriL57wU7jcYpnyZWDwFl9K90Px?usp=drive_link)

Users can download the required large files from the Google Drive
folder and place them in their corresponding project directories.

## Directory Structure

### 01_Study_Area
Contains the Ludhiana district boundary shapefile.

### 02_Grid_Framework
Contains the 250 m × 250 m grid framework and agricultural grid.

### 03_LULC_Data
Contains land-use/land-cover data and the agricultural mask.

### 04_Remote_Sensing_Inputs
Contains NDVI, NDWI, LST, precipitation, DEM, slope,
and other remote-sensing inputs.

### 05_Soil_Data
Contains soil organic carbon, bulk density, sand, and clay datasets.

### 06_Productivity_Data
Contains NPP/productivity data.

### 07_Processed_Grid_Dataset
Contains processed above-ground and below-ground datasets,
training/testing datasets, predictions, and final carbon outputs.
